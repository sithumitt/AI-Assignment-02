# SmartCare AI — Disease Risk Classification

A machine learning pipeline that predicts patient disease risk level (Low / Medium / High) from clinical data, with a Streamlit prototype for interactive predictions.

## Project Structure

```
AI-Assignment/
├── app.py                  # Streamlit decision-support prototype
├── requirements.txt        # Python dependencies
├── src/
│   ├── __init__.py
│   ├── dataset.py           # Task 02: Dataset understanding & quality audit
│   ├── preprocessing.py     # Task 03: Cleaning, encoding, scaling
│   ├── eda.py                # Task 04: Exploratory data analysis
│   ├── models.py             # Task 05 & 06: Model training & evaluation
│   ├── explainability.py     # Task 07: SHAP explainability
│   └── pipeline.py           # End-to-end pipeline runner
├── data/
│   ├── raw/                  # Raw input CSVs
│   └── processed/            # Cleaned/engineered feature CSVs
├── models/                   # Serialized scaler, columns, and best model
└── reports/
    ├── figures/               # EDA and evaluation charts
    └── CCS3440_Technical_Report.pdf
```

## Setup

```bash
pip install -r requirements.txt
```

## Usage

**Run the full ML pipeline** (data understanding → preprocessing → EDA → model training → SHAP explainability):

```bash
python -m src.pipeline
```

**Launch the prediction app:**

```bash
streamlit run app.py
```

## Pipeline Overview

1. **Dataset Understanding** — loads raw data, checks class balance and missing values.
2. **Preprocessing** — filters clinical features (excludes leakage-prone fields), one-hot encodes categoricals, applies stratified 80/20 train-test split, and scales numeric features with `StandardScaler`.
3. **EDA** — generates target distribution, clinical boxplots, and correlation heatmap figures.
4. **Model Training & Evaluation** — trains Logistic Regression, Random Forest, and Decision Tree classifiers; compares Accuracy, Precision, Recall, and F1-score; saves confusion matrices and the best-performing model.
5. **Explainability** — computes SHAP values for the best model and saves a global feature-importance summary plot.

## Notes

- Model artifacts (`models/*.pkl`) and generated figures/data are excluded from version control via `.gitignore` and are regenerated by running the pipeline.
